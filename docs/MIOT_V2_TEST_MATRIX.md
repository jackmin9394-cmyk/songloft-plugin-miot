# MIoT V2 测试矩阵

## 1. 通用规则

每个开发阶段必须：

- [ ] 检查 Git diff
- [ ] 运行 npm run build
- [ ] 运行 npm run validate
- [ ] 完成本阶段手工测试
- [ ] 完成 Voice Memory 回归测试
- [ ] 测试通过后再提交 Git

本矩阵严格分为四类。尚未实现的 V2 功能不得写成阶段 1 当前必须通过的测试；Downloader 集成测试在外部仓库审计完成前保持阻塞。
